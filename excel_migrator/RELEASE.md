# Excel 数据迁移工具 - Release Notes

## v1.2 (2026-04-14)

### 新增功能

- **迁移成功弹窗可直接打开文件**: 点击弹窗的【是】按钮可直接用 Excel 打开生成的文件
- **编辑映射配置对话框添加缩放按钮**: 左下角添加缩小/放大按钮，方便调整窗口大小
- **分割符支持中文顿号**: 源/目标起始单元格输入支持中文顿号（、）作为分割符

### 优化改进

- 迁移结果弹窗优化：
  - 使用 `askyesno` 显示明确的【是/否】按钮
  - 成功时显示生成的文件路径
  - 失败时显示详细失败原因
- 编辑映射配置界面优化：
  - 下拉框和文本框改为 grid 布局，支持自动扩展
  - 修复下拉框滚轮事件冒泡到页面滚动条的问题
  - 修复 IndexError 问题（删除映射后索引失效）
  - 修复方向字段无内容显示问题

### Bug 修复

- 修复编辑映射配置时选择数据源后 Sheet 不跟着动态更新的问题
- 修复 `direction` 枚举访问问题（支持字符串和枚举两种格式）
- 修复迁移成功弹窗按钮文字不匹配问题

### 输入验证增强

- 添加单元格引用格式验证
- 无效输入时提示支持的分割符：`支持: 英文逗号 (,)、中文逗号（，)、中文顿号（、)`
- 错误信息明确指出具体是哪个字段出现问题

## v1.1 (2026-04-13)

### 新增功能

- **界面全新升级**: 从 Streamlit Web 界面切换到 tkinter + ttkbootstrap 桌面 UI
- **写入模式选择**: 支持 skip_nonempty（只写空行）和 overwrite（直接覆盖）两种模式
- **模板 Sheet 选择**: 可指定模板中的目标 Sheet
- **垂直复制支持**: 正确支持纵向模式的多单元格复制
- **输入兼容性增强**: 支持中文逗号、全角字符自动转换

### 功能特性

- 数据源管理：上传、批量导入、更新、删除 Excel 文件
- 模板管理：上传、批量导入、更新、删除模板文件
- 映射配置：导入 JSON 配置、下载示例配置、编辑删除
- 执行迁移：智能匹配、映射预览、文件占用自动处理、批量复制

### 技术特性

- 保留数字格式（number_format）
- 自动调整列宽
- 读取公式计算值
