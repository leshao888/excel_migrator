## 软件简介

本工具用于将 Excel 文件中的数据批量迁移到模板文件中。

**典型应用场景：**
- 将数据源中的计算结果批量填入模板报表
- 多张Sheet数据一一对应复制到目标文件
- 保持原有数字格式的精确迁移

**主要功能：**
- 数据源管理：上传和管理数据源文件
- 模板管理：上传和管理目标模板文件
- 映射配置：通过JSON文件定义数据复制规则
- 执行迁移：一键批量执行数据迁移

## 映射配置

### 什么是映射配置？

映射配置是一个 JSON 格式的文件，定义了：
- 从哪个数据源的哪个 Sheet 读取
- 写入到哪个模板文件的哪个 Sheet
- 从哪个单元格开始复制
- 复制方向（横向/纵向）和长度
- 写入模式（覆盖/跳过已有内容）

### 导入映射配置

1. 点击「📂 导入配置」按钮
2. 选择预先准备好的 JSON 配置文件
3. 填写配置名称
4. 点击「💾 保存」

### 下载示例配置

点击「📥 下载示例配置」可获取一个模板配置文件。

### 编辑映射配置

1. 在列表中选择要编辑的配置
2. 点击「✏️ 编辑选中配置」
3. 修改各项参数
4. 点击「💾 保存」

### 配置文件格式说明

```json
{
  "version": "1.0",
  "default_direction": "horizontal",
  "write_mode": "skip_nonempty",
  "sheet_mappings": [
    {
      "data_source_sheet": "Sheet1",
      "template_file": "模板.xlsx",
      "template_sheet": "目标Sheet",
      "copy_rule": {
        "source_start": "A1",
        "target_start": "B2",
        "direction": "horizontal",
        "length": 10
      }
    }
  ]
}
```

**字段说明：**

| 字段 | 说明 | 示例 |
|------|------|------|
| data_source_sheet | 数据源中的 Sheet 名称 | "Sheet1" |
| template_file | 模板文件名（需与导入的模板匹配）| "报表.xlsx" |
| template_sheet | 模板中的目标 Sheet | "汇总" |
| source_start | 数据源起始单元格 | "F4" |
| target_start | 模板目标起始单元格 | "C5" |
| direction | 复制方向 | horizontal（横向）/ vertical（纵向）|
| length | 复制单元格数量 | 12 |
| write_mode | 写入模式 | skip_nonempty（跳过已有）/ overwrite（覆盖）|

### 数组模式（多组对应）

当有多组数据需要一一对应复制时：

```json
"copy_rule": {
  "source_start": ["F4", "F11", "F12", "F13"],
  "target_start": ["C5", "C15", "C16", "C17"],
  "direction": "horizontal",
  "length": 12
}
```

对应关系：
- F4 → C5
- F11 → C15
- F12 → C16
- F13 → C17

### 垂直复制模式

当需要纵向复制多行数据时：

```json
"copy_rule": {
  "source_start": "F10",
  "target_start": "C5",
  "direction": "vertical",
  "length": 5
}
```

这表示从 F10 单元格开始，向下复制 5 个单元格到 C5 起始位置。

### 写入模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| skip_nonempty | 只写入空单元格，已有内容的会被跳过 | 模板已有部分数据，只补充空白 |
| overwrite | 直接覆盖，无论是否已有内容 | 需要完全替换目标数据 |

### 输入兼容性

系统自动处理以下输入问题：
- 中文逗号（，）自动转为英文逗号（,）
- 大小写不敏感（Horizontal/HORIZONTAL/horizontal 效果相同）
- 全角字符自动转为半角

## 执行迁移

### 执行步骤

1. 进入「🚀 执行迁移」页面
2. 从下拉列表中选择映射配置
3. 系统会自动匹配对应的数据源和模板
4. 查看配置预览确认无误
5. 点击「🚀 执行迁移」

### 查看执行结果

- **✅ 成功**：显示成功迁移的 Sheet 数量和详情
- **⚠️ 跳过**：显示因某种原因跳过的项目及原因

### 文件占用处理

如果模板文件被其他程序（如 Excel）打开，系统会：
1. 自动创建文件副本（文件名加"_副本"）
2. 将数据写入副本
3. 提示副本文件的保存位置

### 数据特性

- **保留数字格式**：会计格式、货币格式等会被保留
- **自动调整列宽**：避免大数字显示为"#####"
- **读取公式结果**：源文件中的公式会读取计算后的值

## 常见问题

### Q: 为什么迁移后数字显示为"#####"？

系统已自动调整列宽。如果仍显示#####，可能是模板文件使用了合并单元格。请尝试使用覆盖模式（overwrite）重新执行。

### Q: 数据迁移不成功怎么办？

1. 确认映射配置中的数据源 Sheet 名称与实际完全一致
2. 确认模板文件名与导入的模板匹配
3. 确认 source_start、target_start、direction、length 设置正确
4. 尝试使用覆盖模式（overwrite）而非跳过模式

### Q: 可以一次执行多个 Sheet 的迁移吗？

可以。在映射配置的 sheet_mappings 数组中添加多条规则即可。

### Q: 如何实现多个单元格的一一对应复制？

使用数组模式：
```json
"source_start": ["A1", "B1", "C1"]
"target_start": ["D1", "E1", "F1"]
```
系统会按索引一一对应复制。

### Q: 垂直复制不工作？

确保 direction 设置为 "vertical"（不是 horizontal），length 设置为要复制的单元格数量。

### Q: 模板文件被占用怎么办？

关闭占用模板文件的 Excel 程序，或让系统自动创建副本。

### Q: 如何修改已导入的配置？

在「映射配置」页面选择配置 → 点击「✏️ 编辑选中配置」→ 修改参数 → 保存
