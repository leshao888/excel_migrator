## 快速开始

### 启动应用

```bash
cd excel_migrator
python -m streamlit run main.py
```

默认端口为 8501，可在命令中指定端口：

```bash
python -m streamlit run main.py --server.port 30085
```

### 界面导航

应用分为 4 个主要页面，通过左侧边栏进行切换：

- **数据源管理** - 管理数据源文件
- **模板管理** - 管理模板文件
- **映射配置** - 配置 Sheet 映射关系
- **执行迁移** - 执行数据迁移操作

## 数据源管理

### 上传数据源

1. 进入「数据源管理」页面
2. 点击「Choose File」或拖拽文件到上传区域
3. 选择 Excel 文件（.xlsx 或 .xlsm）
4. 在「数据源名称」输入框中填写名称（可选）
5. 点击「💾 保存」按钮

### 查看和管理

- 已保存的数据源会显示在页面下方
- 点击展开按钮可查看详情：
  - 文件路径
  - Sheet 数量
  - 文件状态（是否存在、是否被占用）
- 可对数据源进行「🔄 更新」或「🗑️ 删除」操作

### 注意事项

- 文件会被复制到系统的临时目录
- 如果文件被其他程序打开，会提示占用警告
- 更新操作会重新读取文件的 Sheet 信息

## 模板管理

### 上传模板

1. 进入「模板管理」页面
2. 点击「Choose File」或拖拽文件到上传区域
3. 选择模板 Excel 文件
4. 填写模板名称
5. 点击「💾 保存」按钮

### 模板与数据源的区别

- **数据源**: 包含原始数据的 Excel 文件，数据从数据源复制
- **模板**: 接收数据的 Excel 文件，数据写入到模板中

### 文件状态检测

| 状态 | 含义 | 处理方式 |
|------|------|----------|
| ✅ 文件正常 | 文件存在且未被修改 | 无需处理 |
| ⚠️ 文件已修改 | Sheet 数量发生变化 | 点击「🔄 更新」同步 |
| ⚠️ 文件已被其他程序打开 | 文件被占用 | 关闭占用程序 |
| ⚠️ 文件不存在 | 文件被删除或移动 | 重新上传 |

## 映射配置

### 什么是映射配置

映射配置定义了数据从数据源到模板的复制规则，包括：

- 数据源的哪个 Sheet
- 复制到哪个模板文件
- 从哪个单元格开始复制
- 复制到哪个单元格
- 复制方向和长度

### 创建映射配置

1. 进入「映射配置」页面
2. 点击「📥 下载示例文件」获取示例 JSON
3. 根据实际需求修改 JSON 文件
4. 回到应用，点击「Choose File」上传修改后的 JSON
5. 填写配置名称
6. 点击「保存」

### JSON 配置文件格式

#### 单组映射

```json
{
  "version": "1.0",
  "default_direction": "horizontal",
  "default_write_mode": "skip_nonempty",
  "sheet_mappings": [
    {
      "data_source_sheet": "数据源Sheet名称",
      "template_file": "模板文件名.xlsx",
      "copy_rule": {
        "source_start": "F4",
        "target_start": "C5",
        "direction": "horizontal",
        "length": 12
      }
    }
  ]
}
```

#### 多组映射（数组模式）

```json
{
  "version": "1.0",
  "default_direction": "horizontal",
  "default_write_mode": "skip_nonempty",
  "sheet_mappings": [
    {
      "data_source_sheet": "数据源Sheet名称",
      "template_file": "模板文件名.xlsx",
      "copy_rule": {
        "source_start": ["F4", "F11", "F12", "F13"],
        "target_start": ["C5", "C15", "C16", "C17"],
        "direction": "horizontal",
        "length": 12
      }
    }
  ]
}
```

### 字段说明

| 字段 | 说明 | 可选值 |
|------|------|--------|
| version | 配置版本 | "1.0" |
| default_direction | 默认复制方向 | "horizontal" / "vertical" |
| default_write_mode | 写入模式 | "skip_nonempty" / "overwrite" |
| data_source_sheet | 数据源中的 Sheet 名称 | 字符串 |
| template_file | 模板文件名（需与上传的模板匹配）| 字符串.xlsx |
| source_start | 数据源起始单元格 | 字符串或字符串数组，如 "F4" 或 ["F4", "F11", "F12"] |
| target_start | 模板起始单元格 | 字符串或字符串数组，如 "C5" 或 ["C5", "C15", "C16"] |
| direction | 该规则的复制方向 | "horizontal" / "vertical" |
| length | 复制长度（单元格数量）| 正整数 |

### 数组模式说明

当 `source_start` 和 `target_start` 为数组时，系统会按照索引一一对应进行映射：

```
source_start: ["F4", "F11", "F12", "F13"]
target_start: ["C5", "C15", "C16", "C17"]

对应关系：
  F4 → C5
  F11 → C15
  F12 → C16
  F13 → C17
```

### 修改已有配置

1. 在下拉框中选择要修改的配置
2. 点击「修改」按钮
3. 修改各项参数
4. 点击「💾 保存修改」

### 添加/删除映射规则

在修改模式下：
- 点击「➕ 添加新映射」可添加新的映射规则
- 点击映射规则旁边的「🗑️」可删除该规则

### 数据源 Sheet 选择

在修改界面中，可以：
1. 选择数据源（会显示该数据源的 Sheet 数量）
2. 从下拉框中选择具体的 Sheet 名称

## 执行迁移

### 执行步骤

1. 进入「执行迁移」页面
2. 从下拉列表中选择数据源
3. 从下拉列表中选择模板
4. 从下拉列表中选择映射配置
5. 查看「映射预览」确认匹配情况
6. 点击「🚀 执行迁移」按钮

### 映射预览说明

- **✅ 将迁移 X 个 Sheet**: 成功匹配的映射数量
- **⚠️ 数据源中不存在 X 个 Sheet**: 数据源中没有对应 Sheet 的映射
- **⚠️ 未找到对应的模板文件 X 个**: 模板文件名不匹配的映射

#### 数组模式预览

当使用数组模式时，预览会显示每个配对：

```
- 1、GMV预测表 → 模板.xlsx (horizontal, 12格)
  1. F4 → C5
  2. F11 → C15
  3. F12 → C16
  4. F13 → C17
```

### 执行结果

- **成功**: 显示成功迁移的 Sheet 数量和详细信息
- **跳过**: 显示因某种原因跳过的 Sheet 及原因

### 文件占用处理

如果模板文件被其他程序打开，系统会自动：

1. 生成模板文件的副本（文件名加「_副本」后缀）
2. 将数据写入副本文件
3. 在执行结果中提示生成的副本路径

### 数据复制特性

- **保留数字格式**: 复制时保留单元格的 number_format（如货币格式、百分比等）
- **读取公式计算值**: 源文件中的公式会读取其计算结果，而不是公式本身

## 常见问题

### Q: 上传文件失败怎么办？

1. 确认文件格式为 .xlsx 或 .xlsm
2. 确认文件未被其他程序打开
3. 确认文件大小在 200MB 以内

### Q: 映射预览显示"数据源中不存在"？

检查映射配置中的 `data_source_sheet` 是否与数据源中的实际 Sheet 名称完全一致（区分大小写）。

### Q: 映射预览显示"未找到对应的模板文件"？

检查映射配置中的 `template_file` 是否与上传的模板文件名完全一致。

### Q: 执行迁移后数据没有变化？

1. 确认映射配置的 `source_start` 和 `target_start` 单元格地址正确
2. 确认 `direction`（horizontal/vertical）和 `length` 设置正确
3. 尝试使用覆盖模式（overwrite）而非跳过模式（skip_nonempty）

### Q: 如何处理大文件？

应用使用流式处理，对于大文件不会有内存问题。但建议单个 Sheet 的数据量适当控制。

### Q: 配置文件可以包含多个映射吗？

可以，JSON 中的 `sheet_mappings` 数组可以包含多个映射对象，实现一次执行多个 Sheet 的迁移。

### Q: 如何实现多个起点单元格的一一映射？

使用数组格式：

```json
"copy_rule": {
  "source_start": ["F4", "F11", "F12", "F13"],
  "target_start": ["C5", "C15", "C16", "C17"],
  "direction": "horizontal",
  "length": 12
}
```

这会将 F4→C5, F11→C15, F12→C16, F13→C17 同时复制。

### Q: 迁移后数字格式丢失了？

系统会自动保留单元格的数字格式，包括：
- 会计数字格式（如 #,##0）
- 百分比格式
- 货币格式等

### Q: 源文件中的公式数据无法正确迁移？

系统会读取源文件中公式的计算值（而不是公式本身），确保公式结果正确迁移到目标模板。
